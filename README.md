## 📌 نبذة عن المشروع (About)

**نظام أرشيف المستندات (ShareArchiver / DocArchiver Enterprise)** هو نظام أرشفة إلكتروني متكامل مصمم لتحويل إدارة الوثائق الورقية والرقمية إلى بيئة محلية وشبكية منظمة. يهدف البرنامج إلى القضاء على فوضى المستندات، تقليل الاعتماد على المعاملات الورقية، وتسريع وتيرة العمل من خلال محرك بحث وفهرسة ذكي يتيح الوصول للمعلومات في أجزاء من الثانية، مع دعم التصوير والمزامنة المباشرة عبر الجوال.

---

## ✨ المميزات الرئيسية (Key Features)

- **🗂️ تصنيف شجري وهيكلي متقدم:** دعم المجلدات الديناميكية والوسوم (Tags) والتصنيفات المتعددة لتنظيم مرن.
- **🔍 البحث السريع والاسترجاع الفوري:** إمكانية البحث المتقدم عبر الكلمات المفتاحية، التواريخ، الأنواع، أو داخل نصوص الملفات عبر تقنية التعرف الضوئي (**OCR**).
- **📱 المزامنة المباشرة مع الجوال:** التقاط المستندات والسندات بكاميرا الهاتف وإرسالها فوراً إلى الأرشيف عبر الشبكة المحلية.
- **🔒 إدارة الصلاحيات والمستخدمين:** نظام دقيق للتحكم في مستويات الوصول والتعديل والأمان لضمان سرية المستندات.
- **🎨 واجهة مستخدم مرنة وعصرية:** تصميم عملي وبسيط باللغة العربية لتسهيل سير العمل اليومي.
- **📦 دعم صيغ متعددة:** معالجة مستندات PDF، الصور عالية الدقة، والملفات المكتبية بسهولة.
- **💾 حماية البيانات والنسخ الاحتياطي:** حفظ مجلدات الأرشيف (`ArchiveStorage`) وقواعد البيانات بأمان تام عند التحديث أو الترقية.

## 🚀 البدء السريع (Getting Started)

### 1️⃣ متطلبات التشغيل
- نظام تشغيل **Windows 10 (1607+)** أو **Windows 11** أو **Windows Server 2016+** بمعمارية **64-bit (x64)**.
- حزمة **.NET 8 Desktop Runtime (x64)** (يتم التحقق منها وتثبيتها تلقائياً أثناء التثبيت إذا لزم الأمر).

### 2️⃣ التثبيت والتشغيل لأول مرة
1. قم بتحميل ملف المثبّت [DocArchiver\_Enterprise\_v1.exe](https://www.google.com/search?q=https://github.com/sma812020/ShareArchiver/releases/latest/download/DocArchiver_Enterprise_v1.exe) وشغّله بصلاحيات المسؤول.

3. عند تشغيل البرنامج لأول مرة، استخدم بيانات الدخول الافتراضية التالية:
